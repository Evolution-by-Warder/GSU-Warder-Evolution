# Hardware icon masters

User requested colorful dimensional hardware, close in meaning to the original GSU device illustrations, with genuine alpha transparency and no black matte, floor or reflection. These replace the rejected schematic hardware vectors. Navigation arrows now use matching dimensional illustrations at the user’s additional request. Status dots remain unchanged.

The illustrations were generated with the built-in imagegen tool, using the first RAM module as a visual rendering reference. Per-icon prompts and source checksums are recorded in the adjacent provenance manifest. Masters are mechanically contained at512px; the package receives only padded120px RGBA icons generated by `plugin/tools/prepare_system_raster.py` (ImageMagick). No build-time graphics tools or masters are installed on the receiver.

Source preservation and image-size preparation do not recolor, synthesize alpha, remove backgrounds or alter the generated subject.
