# Funkčný audit pre GSU 0.41.5

Stav k 26. novembru 2026. Porovnanie vychádza z uvedených revízií, verejných opisov a statickej kontroly balíkov. Na prijímači nebežal žiadny cudzí plugin. Vývojová vetva obsahuje vlastný kód a používa existujúce rozhrania Enigma2. Testy v plugin/tests/test_diagnostic_centres.py používajú náhrady natívneho API; migrácia balíka v CI beží so skutočným OPKG v dočasnom koreni.
