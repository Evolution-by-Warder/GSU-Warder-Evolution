## Private backup backend checkpoint

Optional AES-256-GCM with scrypt (N=32768, r=8, p=1), fresh salt/nonce, authenticated format and password minimum 12 characters. No custom crypto fallback, no installation or network. If the receiver lacks cryptography, private backup is unavailable. Explicitly allow only the native YouTube API key and validated Radio favourites/custom lists in encrypted form; no OAuth/session tokens, history, credentials embedded in URL userinfo, or arbitrary settings. Plaintext save validates before writing; encrypted rollback is required for private restore. Actual receiver provider availability, masked password UI and failure/recovery testing remain open. The backend is not yet exposed in GUI; ordinary portable backup is unchanged. Tests include rejection of plaintext, wrong password/tamper, encrypted rollback and preservation of Radio history; crypto tests skip if provider missing.
